Aiwa POS58 Print Service for Windows 7 SP1 64-bit

1. Extract all files to a new folder.
2. Double-click install.bat.
3. Keep the Aiwa POS58 Print Service window open.
4. Open http://127.0.0.1:17891/health in Chrome.
5. Continue only when the page displays OK POS58.

The service is precompiled for Windows 7 and does not use PowerShell or .NET.
It only listens on 127.0.0.1 and prints RAW ESC/POS data to printer POS58.
