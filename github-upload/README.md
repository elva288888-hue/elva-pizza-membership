# 爱娃披萨店会员管理

这是爱娃披萨店会员管理系统，用于记录会员充值、赠送、消费、余额和交易流水。

## 使用方式

直接打开 `index.html` 即可使用。

当前已开启 CloudBase 云端同步，数据会通过云函数保存到腾讯云 CloudBase。

CloudBase 状态：

- 环境 ID：`elva-pizza-test-d1far2ax4213b224`
- 云函数：`membershipApi`
- 数据集合：`stores`、`staff`、`members`、`transactions`、`bonusrules`、`login_codes`

## 功能

- 店员手机号验证码登录骨架
- 会员新增和编辑
- 充值、消费和余额记录
- 可配置充值赠送规则
- 按会员、类型、日期查询流水
- 打印会员交易记录或当前查询结果
- 数据导入和导出
