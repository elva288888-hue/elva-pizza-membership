# 爱娃披萨店会员管理

这是一个本地网页版本的会员管理系统，用于记录会员充值、赠送、消费、余额和交易流水。

## 使用方式

直接打开 `index.html` 即可使用。

数据保存在当前浏览器本地。需要备份或换电脑时，请使用系统里的“导出数据”和“导入数据”。

## 功能

- 店员手机号验证码登录骨架
- 会员新增和编辑
- 充值、消费和余额记录
- 可配置充值赠送规则
- 按会员、类型、日期查询流水
- 打印会员交易记录或当前查询结果
- 数据导入和导出
