## 已覆盖

### 小程序点餐页

- 加入购物车、减少数量
- 购物车数量与金额计算
- 商品分类筛选
- 预约取餐日期、时间必填
- 配送地址必填
- 会员充值金额范围校验
- 加入会员必须取得微信手机号授权码
- 订单草稿中的商品、取餐方式、备注和支付方式

### 云函数

- 会员余额支付扣款
- 订单支付状态写入
- 交易流水写入

- 售罄商品不能下单

- 两端读取相同商品数据
- 后台商品数据更新后消费者端刷新可见
- 测试服务器使用隔离数据文件
- 合并数据时保留最新版本及删除标记

- 微信手机号授权弹窗
